# 第 5 章：整理報名資料與產生試算表

目標：依明確規則清理 CSV，產生四張工作表，並直接讀取輸出的 XLSX 驗證儲存格內容及型別。

```bash
python ch05/build_report.py --input ch05/registrations.csv --output output/ch05 --check-only
echo $?
python ch05/build_report.py --input ch05/registrations.csv --output output/ch05
echo $?
```

從儲存庫根目錄執行。`--check-only` 不寫入檔案，仍需提供 `--output`。兩次執行都預期回傳 `3`，表示資料中有待查項目；第二次會完成報表。

| 分類／統計 | 預期值 |
| --- | ---: |
| 原始筆數 | 8 |
| 有效資料 | 4 |
| 待查資料 | 3 |
| 重複紀錄 | 1 |
| 有效資料總額 | 5,400 |
| 已付款 | 3,900 |
| 未付款 | 1,500 |

金額只接受正整數，允許正確的千分位逗號；付款狀態只接受「已付款」或「未付款」。同編號內容衝突時整組列入待查，不擅自挑選。金額表示法不同（例如 `1200` 與 `1,200`）也會視為內容不一致，需人工確認。

成果包括 `clean.csv`、`issues.csv`、`duplicates.csv`、`summary.json`、`report.ods`、`report.xlsx` 及 `verification.json`。XLSX 工作表為「課程彙總」「有效明細」「待查資料」「重複紀錄」。報名編號如 `001` 以文字型別保留；金額為數值。

報表是 Python 計算後的數值快照，修改明細不會自動重新計算彙總。請重新執行程式產生新報表。
