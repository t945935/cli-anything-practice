# 第十六章交接演練摘要

演練對象是本書手寫的 practice-textmeter 0.1.0 與文字統計後端 0.1.0，不是官方生成 harness。

本輪先建立兩個 wheel，再整理安裝說明、固定雜湊的 requirements.txt、來源副本、驗收器與版本紀錄。完整資料複製到原始儲存庫以外的目錄，使用新建虛擬環境測試。

| 檢查 | 實際結果 |
| --- | --- |
| 接收副本 SHA256SUMS | 全部通過 |
| 安裝前的環境 | 尚未安裝 textmeter 與 textmeter_reference |
| 固定雜湊的本地 wheel 安裝 | 結束碼 0 |
| pip check | 結束碼 0 |
| 模組來源 | 兩個模組均來自新環境的 site-packages |
| 命令契約驗收 | 16 passed、0 failed、0 blocked；結束碼 0 |
| 故障副本 SHA256SUMS | 改動 wheel 被辨識；結束碼 1 |
| 故障副本在另一新環境安裝 | pip 因雜湊不符拒絕；結束碼 1 |

故障練習只修改另一份副本，在 wheel 結尾加入額外位元組，沒有更新兩份雜湊清單。正常交接資料保持不變。

四項整理工具測試通過，完整讀者專案共 62 項通過。測試涵蓋版本與來源不符、損壞 ZIP、複製內容與雜湊一致，以及既有輸出不得覆寫。

演練在同一台 Ubuntu 主機上進行。它證明這份資料在該主機的新環境中可獨立安裝並通過本章驗收；不代表已驗證其他作業系統、每次建置位元組一致、數位簽章或完整供應鏈安全。

wheel、完整安裝日誌與執行產物保留在本機練習目錄；儲存庫提供建立方式與摘要，不把本輪 wheel 冒充永久固定的官方發行版。
