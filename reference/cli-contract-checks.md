# 第十五章 CLI 驗收對照

本摘要來自 Ubuntu 環境的實際執行。待測命令是本書手寫的 `practice-textmeter` 0.1.0，呼叫 `cli-anything-practice-textmeter-core` 0.1.0；兩者以本機套件安裝在獨立環境。

這是驗收器與參考介面的測試，不是 CLI-Anything 生成成果的測試結果。讀者生成的 `cli-anything-textmeter` 需另外驗收。

| 模式 | passed | failed | blocked | 結束碼 |
| --- | --- | --- | --- | --- |
| 正常參考命令 | 16 | 0 | 0 | 0 |
| boolean-count | 9 | 7 | 0 | 1 |
| stdout-noise | 0 | 16 | 0 | 1 |
| overwrite | 13 | 3 | 0 | 1 |

boolean-count 讓正常分析與匯出回傳布林型別，驗收器拒絕把 true 當成整數。stdout-noise 在 JSON 前加入說明文字，所有案例的 stdout 都無法作為單一 JSON 解析。

overwrite 未拒絕再次匯出、輸出等於來源及既有符號連結，因此三項失敗。輸出等於來源與符號連結案例，另觀察到受保護檔案內容改變；影響範圍限本輪新建的測試副本。

額外確認：對既有輸出目錄重跑，結束碼為 2，原報告不變；命令不存在時，結束碼為 2，不建立報告目錄。

驗收器的八項單元測試通過；完整讀者專案共 58 項通過。其中逾時分支使用可控的模擬例外驗證，沒有宣稱實測所有作業系統的程序終止行為。

完整命令紀錄與測試檔案保留在執行者的 output 目錄，不隨儲存庫發布。16 項通過代表本章列出的命令契約符合，不包含原始碼審查、REPL、完整封裝可攜性或安全隔離。
