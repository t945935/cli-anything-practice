# 已知限制與驗證範圍

- **軟體層次**：CLI-Hub 負責查找與安裝 CLI，實際功能仍取決於各軟體的 CLI、後端與原生程式。
- **版本**：範例針對 `requirements.txt` 指定的版本／commit 撰寫。更新後需重新驗證命令與輸出。
- **文件匯入**：第 4 章是匯入內容後重建文件，適合簡單文字案例；無法承諾樣式、圖片、表格與頁首頁尾保真。有版面保真需求時，應另外評估 LibreOffice 原生轉檔並逐份比對。
- **PDF 檢查**：檔頭與文字擷取可找出部分錯誤，無法證明完整保留來源內容，也無法判斷斷行、重疊或字型是否合宜。
- **試算表公式**：教學環境曾在 CLI 1.0.1 的公式匯出測試得到 `#VALUE!`，因此第 5 章採 Python 計算後寫入數值。本案例不涵蓋即時公式報表，也不推論所有公式都不可用。
- **圖片後端**：第 6 章只驗證 Pillow 渲染，不等同測試 GIMP 原生編輯能力；不處理色彩管理、透明素材、動畫或自動主體裁切。
- **平台**：已驗證 Ubuntu 24.04。WSL 安裝指引供 Windows 讀者參考，其他環境需自行驗證。
- **資料範圍**：報名 CSV 是小型教學案例，金額限正整數，不涵蓋退款、折扣、稅務或部分付款。不要把它當成完整帳務系統。

各章會保留輸出與命令紀錄，讓讀者檢查結果。紀錄可能包含來源路徑和文件文字；公開分享前請先檢視內容。
