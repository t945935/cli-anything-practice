## 練習 A：驗證不覆寫

執行一次成功案例後，以相同輸出目錄重跑。程式應拒絕覆寫；前次結果應保持不變。再換新目錄執行。

## 練習 B：觀察 dry-run

執行第 4、6 章的 `--dry-run`，確認列出的計畫合理，而且輸出目錄尚未建立。修改來源後重新預覽，注意命令與尺寸變化。

## 練習 C：測試衝突報名編號

複製第 5 章 CSV，加入同編號但不同課程或付款狀態的一筆資料。整組應列為待查，而不是任意保留第一筆。使用 `--check-only` 先查看分類筆數。

> 請閱讀這個 repo 的 README 與第 4 章說明，先對範例資料執行 dry-run，再輸出到新的 output 子目錄。完成後讀取 report.json，說明成功、失敗與略過的原因，並列出仍需人工檢查的項目。
