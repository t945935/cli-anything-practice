# 工具箱維護紀錄範本

複製此範本到自己的維護資料夾，再填入本次實際紀錄。不要只勾選「命令成功」而省略成品檢查。

| 項目 | 本次紀錄 |
| --- | --- |
| 日期與負責人 | 待填 |
| 變更目的 | 待填：修正哪個問題或增加什麼能力 |
| 變更範圍 | 待填：原始碼／Python 套件／原生軟體／字型／設定 |
| 變更前 Git commit 與工作目錄狀態 | 待填 |
| 變更後 Git commit 與工作目錄狀態 | 待填 |
| 修改前盤點 | 待填：snapshot.json 位置 |
| 修改後盤點與差異 | 待填 |
| 測試環境 | 待填：checkout、venv、原生軟體版本 |
| 保留的舊環境 | 待填：如何重新使用，是否與新環境共用系統軟體 |
| 決定 | 待填：採用／暫緩，以及原因 |

## 發現與處理

- 已知限制是否改變：待填。
- 文件與命令範例是否需要更新：待填。
- 尚未解決的問題：待填。
- 返回舊環境的實際步驟與限制：待填。
- 舊成果是否保留：待填；重新產生時應使用新輸出目錄。
